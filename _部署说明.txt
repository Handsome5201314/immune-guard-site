免疫卫士官网 · 部署说明（2026-11-24 更新）
================================

一、这个包里有什么
  index.html        官网首页
  download.html     下载页（版本信息优先读同目录 version.json，后台再与 GitHub 校对）
  version.json      版本缓存：最新版本号、安装包大小、SHA-256、历史版本列表
  assets/ip.png     品牌角色图（唯一图片资源）

二、怎么部署
  1. 解压，把 index.html、download.html、version.json、assets/ 一起上传到网站目录
  2. 可以放根目录，也可以放子目录（线上现挂在 /immune-guard/），页面内部全是相对路径，不用改
  3. 不需要 Node、不需要构建、不需要数据库，任何静态 Web 服务都行
     - Nginx / Apache：直接丢进 root 目录
     - 腾讯云 COS / 阿里云 OSS：开启静态网站功能后上传
     - Vercel / Netlify / Cloudflare Pages：整个目录拖进去

三、Nginx 参考配置
  location / {
      index index.html;
      try_files $uri $uri/ /index.html;
  }
  # 图片缓存
  location /assets/ {
      expires 7d;
      add_header Cache-Control "public";
  }
  # 版本缓存不要长缓存，发新版后要立刻生效
  location = /version.json {
      add_header Cache-Control "no-cache";
  }

四、版本数据怎么更新（重要）
  - 页面的数据来源有两条：① 同目录 version.json（秒开）② GitHub Release API（后台校对）
  - version.json 由本机脚本 scripts/sync_versions.py 生成：
      cd 免疫卫队伍/03-产出/官网设计
      python scripts/sync_versions.py
    脚本读取项目根目录 .env 里的 GitHub token，只在生成阶段使用，不会写进网页。
  - 发新版流程：在 GitHub 建 Release（CI 会自动同步 APK 与更新说明）→ 跑一次上面的脚本
    → 重新上传 version.json。即使忘了上传，页面也会自动从 GitHub 拉最新数据。
  - GitHub 接口公开、允许跨域；服务器访问 GitHub 慢时页面不会卡住：
    version.json 先渲染，GitHub 请求 6 秒超时后静默降级。
  - 历史版本（v0.6.0 / v0.5.2 / v0.5.1 / v0.5.0）只做版本记录，不提供安装包下载。

五、上线前请替换的占位内容

  - 联系方式、隐私政策、用户协议链接
  - 「预约体验」按钮目前锚点到页内 #contact，需接表单或企微活码
